# Garden-app

## Overview
Users will respond to prompts and receive statements regarding plant care

## Features
- Command line interface running python
- Responses designed for "flower" and "vegetable" along with "summer" or "winter" season choices
- Program exits upon user choice

## Technologies used:
- Python
- Git

## Installation
- Clone repository <https://github.com/LeahCampbell1/garden-app>
- Open the garden app directory in the terminal
- Run "garden_advice.py" with either of the following commands

```bash
python garden_advice.py
```

```bash
py garden_advice.py
```
